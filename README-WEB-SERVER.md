# TrendRadar Web服务器使用指南

## 📖 简介

TrendRadar Web服务器提供了通过浏览器访问新闻分析报告的功能，支持：
- ✅ 在浏览器中查看最新生成的报告
- ✅ 点击"刷新获取最新"按钮重新运行分析任务
- ✅ 支持局域网内其他设备访问（手机、平板、其他电脑）

## 🚀 快速开始

### 1. 启动Web服务器

**Windows系统：**
```bash
start-web-server.bat
```

**Mac/Linux系统：**
```bash
chmod +x start-web-server.sh
./start-web-server.sh
```

**或直接使用Python：**
```bash
python web_server.py --port 8080
```

### 2. 访问网页

启动服务器后，会显示以下信息：
```
本地访问: http://localhost:8080
局域网访问: http://192.168.x.x:8080
```

**重要提示：**
- ❌ **不要直接打开HTML文件**（如 `file:///E:/github/TrendRadar/output/.../当日汇总.html`）
- ✅ **必须通过Web服务器访问**（如 `http://localhost:8080`）

如果直接打开本地HTML文件，刷新功能将无法使用！

## 📱 其他设备访问

### 方式一：同一局域网访问（推荐）

1. **确保服务器和客户端在同一WiFi/局域网**

2. **查找服务器IP地址**
   - 启动服务器时，会显示"局域网访问"地址
   - Windows：在命令行运行 `ipconfig`，查看"IPv4 地址"
   - Mac/Linux：在终端运行 `ifconfig` 或 `ip addr`

3. **在客户端设备访问**
   - 打开浏览器（手机、平板、其他电脑）
   - 输入：`http://服务器IP地址:8080`
   - 例如：`http://192.168.1.100:8080`

4. **配置Windows防火墙**（如果无法访问）
   - 打开"Windows Defender 防火墙"
   - 点击"高级设置"
   - 选择"入站规则" → "新建规则"
   - 选择"端口" → 下一步
   - 选择"TCP"，输入端口 `8080`
   - 选择"允许连接"
   - 应用到所有配置文件
   - 命名规则，完成

### 方式二：内网穿透（外网访问）

如果需要从外网访问，可以使用内网穿透工具：

1. **使用ngrok**（简单快速）
   ```bash
   ngrok http 8080
   ```
   会生成一个公网地址，如 `https://xxxxx.ngrok.io`

2. **使用frp**（自建服务器）
   - 配置frp服务器和客户端
   - 设置端口转发

3. **使用其他内网穿透工具**
   - ZeroTier
   - Tailscale
   - 花生壳等

## 🔧 故障排除

### 问题1：点击刷新按钮提示"刷新失败，请重新获取"

**原因：** 直接打开了本地HTML文件（file://协议），无法调用API

**解决方案：**
1. 关闭当前打开的HTML文件
2. 启动Web服务器（运行 `start-web-server.bat`）
3. 在浏览器中访问 `http://localhost:8080`
4. 此时刷新功能即可正常使用

### 问题2：其他设备无法访问

**检查清单：**
- [ ] Web服务器是否正在运行？
- [ ] 服务器和客户端是否在同一局域网？
- [ ] 是否使用了正确的IP地址和端口（8080）？
- [ ] Windows防火墙是否允许8080端口？
- [ ] 路由器的防火墙/访问控制是否阻止了连接？

**调试步骤：**
1. 在服务器上，访问 `http://localhost:8080` 确认服务器正常运行
2. 在服务器上，使用其他浏览器访问 `http://服务器IP:8080` 测试
3. 在客户端，ping服务器IP地址，确认网络连通
4. 检查防火墙设置

### 问题3：刷新任务执行失败

**检查：**
1. 查看服务器控制台的错误信息
2. 确保配置文件 `config/config.yaml` 正确配置
3. 确保网络连接正常（爬取需要访问外部网站）

## 📝 API接口说明

Web服务器提供以下API接口：

### 1. 获取任务状态
```
GET /api/status
```

返回：
```json
{
  "running": false,
  "last_run_time": "2026-01-17 14:30:00",
  "error": null
}
```

### 2. 触发新任务
```
POST /api/trigger
```

返回：
```json
{
  "success": true,
  "message": "任务已启动",
  "running": true
}
```

## 💡 使用技巧

1. **自动刷新页面**
   - 点击"刷新获取最新"后，任务完成后页面会自动刷新
   - 显示最新的分析结果

2. **保存报告**
   - 使用"保存为图片"功能可以保存整个报告
   - 使用"分段保存"可以将长报告分段保存为多张图片

3. **后台运行**
   - 刷新任务在后台运行，不会阻塞页面
   - 可以继续查看之前的报告，等待新报告生成

4. **多设备同步**
   - 所有设备访问的是同一份最新报告
   - 在一个设备上刷新后，其他设备刷新页面即可看到新结果

## 🔒 安全提示

⚠️ **注意：** Web服务器默认监听所有网络接口（0.0.0.0），这意味着同一局域网内的任何人都可以访问。

**建议：**
- 仅在内网环境使用
- 如需外网访问，请使用内网穿透工具并配置认证
- 不要在生产环境暴露端口
- 考虑添加身份验证（可选扩展）
